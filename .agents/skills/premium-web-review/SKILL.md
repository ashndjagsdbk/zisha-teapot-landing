# Premium Web Review

Review the current webpage as a strict art director and conversion designer.

## Check These Problems

Look for:
- generic card grids
- weak first screen
- no dominant visual
- too much copy
- poor image hierarchy
- cheap gradient backgrounds
- excessive white background
- inconsistent spacing
- weak CTA
- decorative animations
- mobile layout that feels like stacked blocks
- visual system not matching the product

## Required Output

Return:

1. Overall score out of 10
2. The 5 biggest visual weaknesses
3. The 5 highest-impact fixes
4. Which sections should be redesigned first
5. Specific code/component changes needed
6. Whether the page feels:
   - premium
   - product-led
   - memorable
   - conversion-ready

## Hard Standard

If the page looks like a generic template, say so directly.

Do not praise weak design.
Do not recommend small tweaks if the section needs redesign.
